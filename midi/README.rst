This this the pure Python part of python-midi (https://github.com/vishnubob/python-midi)

Especially it is the content of this particular pull request that make the project compatible with Python 3: https://github.com/vishnubob/python-midi/pull/130

Note that this code is under the MIT license unlike the rest of the project.

The upstream project ostensively has received an update that should make it Python 3 compatible but this has not worked for me. So while shipping this code this way is less than ideal it is the easiest way for now.
